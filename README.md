# Happy Tales

Happy Tales is a colourful storytelling and learning website for kids, parents, and teachers. It includes fun stories, reading activities, learning games, and an adventure quest.

## Features

- A library of stories with unique covers
- Educational games for different grades
- Starpath Quest adventure game with levels, bosses, and checkpoints
- Parent, teacher, and learner account options
- Saved progress in the browser

## Built With

- HTML
- CSS
- JavaScript
- Image assets in the assets folder

## How To Use

Open `index.html` to start the website.

Make sure the `assets` folder is uploaded too, because it contains the images, covers, maps, and flags.
